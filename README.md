# Controle de Despesas e Receitas MM

Aplicativo financeiro, documental e de aprovação da **FLÁVIO MARQUES ADVOGADOS ASSOCIADOS**.

## Padrão oficial do projeto

- GitHub: código-fonte e versionamento
- Firebase Authentication: usuários e autenticação
- Cloud Firestore: dados e fluxos
- Firebase Storage: demonstrativos e comprovantes
- Firebase Hosting: publicação
- Deploy: PowerShell + Firebase CLI
- Sem Base44, Lovable ou Supabase

## Identidade do frontend

- Escritório: **FLÁVIO MARQUES ADVOGADOS ASSOCIADOS**
- Aplicativo: **Controle de Despesas e Receitas**
- Repositório técnico: `controle-despesas-receitas-mm`

## Módulos previstos

- Dashboard gerencial
- Despesas / Tesouraria
- Recebimento de Alvarás
- Tesouraria / Receitas
- Aprovações da Diretoria
- Plano de Contas (classificação opcional)
- Contabilidade e exportação mensal
- Arquivo de documentos
- Auditoria
- Usuários e permissões
- Tour Guiado por perfil
- DICAS (botão vermelho)
- Como Usar

## Regra de cálculo dos recebimentos

Campos de percentual e valor permanecem editáveis e vinculados ao valor total do alvará: informar um recalcula automaticamente o outro.
